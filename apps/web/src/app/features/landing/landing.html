How iThemba works

Simple, transparent, and built for Lesotho

1. Register

Sign up via the web app or M-Pesa super app. KYC verified by Vodacom M-Pesa.

2. Save

Contribute monthly via debit order (R500–R10,000) or top up via M-Pesa anytime.

3. Book

Find and book accredited doctors, dentists, pharmacies and hospitals in your network.

4. Pay

Get a visit code via SMS. Show it at the clinic. Payment authorised instantly from your HSA.
